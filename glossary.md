# Glossary - Deltora Quest: 7-tsu no Houseki

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (asked of the user once; options and reasons in docs/decisions.md)
- Honorifics: dropped. Name order: Western.
- Name source: the English Deltora Quest novels (Emily Rodda); anime-only terms: English dub, then Hepburn.
- Credits: English (names romanized, roles translated).
- Register: plain, warm English for young readers, matching the novels' tone; no JP flavour words. Sound effects:
  English words ("Caw!", "Crash!"), asterisks only for pure sounds.
- Abbreviations: none; full names and terms everywhere, prefer engine changes over shortening.

## Style rules
- Punctuation map: 「」 -> "...", 『』 -> keep the colour codes, drop the brackets (or '...'), …… / ・・・ -> ...,
  ！？ -> ?!, ―― -> --. Plain ASCII only. British/Australian spelling as in the novels (Grey, colour, armour).
- Voices: docs/style-reference.md. Line layout and limits: docs/translator-brief.md.

Sources: novel = series 1 novels; anime = 2007 anime / English dub; game = coined by this game. `?` in notes = unverified, ask before relying on it.
